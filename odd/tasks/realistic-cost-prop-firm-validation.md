- L5 (2026-11-13) — **DEFECT FOUND in `detector/backtest/simulate.py` (`_resolve_trade`, lines 218/241/247): the configured trading cost is UNDERCHARGED by 2× on every trade whose partial leg fires, at the default `partial_fraction=0.5`.** Not fixed here (S4/this doc's header scope this task research-only); recommend a separate task.
  - Mechanism: `cost_leg1 = partial_fraction * C`, `cost_leg2 = C - cost_leg1`, each leg's R computed at FULL size via `net_r_multiple`, then `blended_r = pf*r1 + (1-pf)*r2`.   - **The three weaknesses that remain, in order of how much they should temper the above:**
    1. **The stops are implausibly tight for live execution.** Median 8.6 pips, p25 6.3, min 3.6; 1AM's median is 7.4.
