This guarantees byte-for-byte canonical formatting (the format `run_preflight`'s `authorization_manifest_binding` check actually compares against) instead of risking a hand-edit that passes visual review but fails the exact-bytes check.
- **S5 — Scope discipline.** No change to the protocol file, the statistical methodology (bootstrap config, MEI, nomination rule, cutoffs), the dataset, or the `protected_paths` list itself. This is purely "the code these protected files now point to is a commit further down the SAME branch, reflecting one already-landed, already-reasoned bugfix" — not a re-litigation of anything the protocol decided.
